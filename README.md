# wabot-sketch

wabot = WhatsApp Bot.

LIFTeracy's WhatsApp interface layer: receives WhatsApp webhooks, forwards them to pp-sketch, sends replies. NestJS.

```bash
cp .env.example .env
npm ci
npm run start:dev
npm test
```
